# RMIT Vietnam Global Mobility: interactive prototype

A concept website for international staff at RMIT University Vietnam. It explains work permit and TRC renewal and the exit visa / repatriation process, and gives each person a plan with their own dates.

**Open it:** `index.html` in any browser. No build step or server needed.

## What's in the prototype

- **Home:** intro video slot (the 2–3 minute animation), links to the Renewal and Departure guides, and the no-travel rule.
- **Personal plan:** a short set of questions builds a step-by-step timeline with dates, documents and the no-travel window.
- **My account hub:** My plan, Documents (upload and submit), Updates (reminders), Profile & settings.
- **Calendar:** add any step to Outlook or Google Calendar.
- **Assistant:** chat panel with sample answers.

## Prototype notes

- All timings are **sample values** until Global Mobility confirms the real ones.
- Plans, ticks and uploads are kept **in the browser only**. Nothing is sent anywhere.
- Contact details, the RMIT logo and the Museo font are placeholders.
- The live version would add RMIT single sign-on, secure document storage on RMIT systems, email/Teams reminders and a Global Mobility admin view.
